# Doggo Memory Game

Um jogo da memória com fotos de doguinhos! Encontre todos os 8 pares de cartas no menor tempo possível.

## Como jogar

1. Clique em uma carta para revelá-la
2. Clique em uma segunda carta para tentar encontrar o par
3. Se as cartas forem iguais, elas ficam viradas com borda dourada
4. Continue até encontrar todos os 8 pares
5. Seu tempo é registrado — tente ser o mais rápido!

## Rodando o projeto

```bash
npm install
npm start
```

O app abre em [http://localhost:3000](http://localhost:3000).

## Scripts

| Comando | Descrição |
|---------|-----------|
| `npm start` | Inicia o servidor de desenvolvimento |
| `npm run build` | Gera o build de produção em `build/` |
| `npm test` | Roda os testes com Jest |

## Tecnologias

- React 16 com hooks
- [Create React App](https://github.com/facebook/create-react-app)
